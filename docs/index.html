Quick start

From file to full view in seconds.

Filion supports direct opening and reusable scan folders, without requesting broad storage access.

Download the current APK from GitHub Releases and install it on Android 10 or newer.

Folder scanning

Your model shelf, without broad storage access.

Select only the folders you want Filion to scan. Android grants persistent read access through the Storage Access Framework, and you can remove each grant from Settings.

Before you open a model.

Filion currently focuses on GLB, the binary form of glTF. Files can be selected inside Filion or opened from another Android app.

No. The Android app does not declare internet permission and includes no cloud, analytics, advertising, or telemetry service.

Android's Storage Access Framework lets you grant read access to only the folders you select. Filion saves those grants so your local model list can be refreshed later.
