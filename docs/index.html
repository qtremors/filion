Engine & Features

Built for Precision 3D Inspection

Experience fluid GLB rendering powered by Google Filament with responsive touch controls and folder management.

01 / RENDERING

Real-Time Filament Engine

Physical-based rendering (PBR) computes realistic reflections, surface roughness, and metallic highlights at a locked 60 FPS.

02 / GESTURES

Natural Orbital Touch

Rotate with a single finger, pan with two-finger drags, and pinch or use HUD sliders to zoom into fine mesh details.

03 / ENVIRONMENT

Dynamic Scene Lighting

Tune environmental illumination on the fly and switch between adaptive theme, pure black OLED, and white studio backdrops.

04 / SCANNER

SAF Folder Discovery

Choose folders via Android Storage Access Framework. Filion scans them recursively and lists all GLB models with persistent grants.

05 / INTEGRATION

Direct Android Open With

Tap any `.glb` model in your browser, file manager, or chat app to immediately open and view it inside Filion.

06 / PRIVACY

100% Offline by Design

Filion declares zero network permissions. Your proprietary 3D models and device metadata never leave your local storage.

Frequently Asked Questions

Common Questions

Everything you need to know about Filion's technology and operation.

Which 3D file formats does Filion support?
Filion currently supports GLB, the self-contained binary packaging of glTF 2.0. Binary GLB files bundle 3D meshes, textures, PBR materials, and shaders into a single file for instantaneous loading.
How do the 3D viewer gestures work?
Drag with one finger to rotate the camera around the 3D model. Use two fingers to drag and pan across the scene. Pinch or use the on-screen zoom slider to inspect mesh details up close.
How does folder scanning work with Android permissions?
Filion uses Android's Storage Access Framework (SAF) system folder picker. When you select a directory, Android grants Filion persistable read access only to that folder tree. Filion does not need or request full shared storage permissions.
What Android versions are supported?
Filion runs on Android 10 (API level 30) and newer, supporting compileSdk 37, modern dynamic colors (Material You), and both phone and tablet form factors.
Where can I report bugs or submit feature requests?
Submit issues and feature requests on GitHub Issues, or join the discussion in the Discord Community.
